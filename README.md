# 学生发展优势测评

全新、独立的 Student-Only 项目。完整需求见 [产品需求](docs/product-requirements.md)。

## 当前状态

项目初始化完成；正式题库尚待用户指定。本仓库没有导入任何旧题库、评分映射、画像逻辑或旧项目架构。

## 实施顺序与验收

1. A：确认源文件，逐项审计题库，建立唯一 Question Bank，再实现测评、响应校验、评分和阶段性画像。验证首末题、ID、维度映射、评分方向、刷新恢复，以及开发测试模式共用真实数据链。
2. B：仅在 A 通过后实现个人信息分步填写、自动保存与 Development Context。
3. C：整合测评和真实经历，生成学生报告、结果页与下载。
4. D：预留导师分析资料的结构化数据接口，不创建 Prompt 或接入 AI。

题库尚未确认，因此 A 尚未通过，B/C/D 尚未实施。

## 数据源规则

- 用户确认的最新原始题库是唯一事实来源；保留源文件及其摘要以便追溯。
- 不从旧项目补全题目、维度、量表、计分或反向题规则。
- 不确定的计分信息必须记录并确认，不能自行推断。
- 测评、评分、画像、开发测试数据必须读取同一个 Question Bank。

## 产品边界

学生流程：完成测评 → 补充个人信息 → 生成结果。

阶段性「我的发展画像」与最终「我的发展报告」分开。最终报告结合个人信息，不提供专业、大学或职业排名。

旧项目仅供视觉与成熟交互参考，保持原样。此仓库不配置旧项目 remote，也未创建 GitHub 仓库或部署。
